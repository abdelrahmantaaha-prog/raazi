# Corpus Inbox — browser extension

Sends the article you are reading into the Corpus inbox, as your browser sees
it. The feeds fetch a page as a stranger; for a subscription outlet that means a
headline and a sentence, and the inbox then asks you to paste the article. This
skips the paste: signed in, paywall open, one click.

Works in Brave, Chrome and Edge (Manifest V3).

## Install

1. Open `brave://extensions` (or `chrome://extensions`).
2. Switch on **Developer mode** (top right).
3. **Load unpacked** → choose this `extension` folder.
4. Pin the icon. Right-click it → **Options** if Corpus is not at
   `http://127.0.0.1:5400`, or is in LAN mode and needs its token.

## Use

- Click the icon on any article: it shows the title, the outlet, the picture
  and a word count, and says whether that is enough to read. **Send to inbox**
  puts it in the inbox with the full text, marked *full text*.
- **Alt+Shift+C** does the same without opening the popup; the icon shows ✓ or !.
- If Readability picks the wrong part of a page, select the article text first —
  a selection of 400 characters or more is sent in its place.

The item behaves like anything a feed brought in: it groups with the running
story, counts in the week when kept, can be discarded and undone. Sending an
address that is already waiting replaces its text, which is exactly what
pasting does.

## Files

- `readability.js` — Mozilla's Readability, unmodified, Apache 2.0
  (`READABILITY-LICENSE.md`).
- `content.js` — runs in the page; returns the article and the page's metadata.
- `background.js` — posts to `POST /api/inbox/clip`, with the token when set.
- `popup.*`, `options.*` — the two small pages.

Icons: `icon16.png`, `icon48.png`, `icon128.png` are generated by
`node scripts/extension-icons.mjs` and checked in beside this file.
